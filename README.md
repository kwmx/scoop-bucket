# kwmx Scoop bucket

[Scoop](https://scoop.sh) manifests for tools published by [kwmx](https://github.com/kwmx).

## Install

```powershell
scoop bucket add kwmx https://github.com/kwmx/scoop-bucket
scoop install kwmx/gignore
```

## Available apps

| App | Description |
| --- | --- |
| [`gignore`](https://github.com/kwmx/gignore) | Build and maintain .gitignore files from a library of templates |

The manifests in `bucket/` are generated by each project's release workflow. Don't edit them by hand; changes are overwritten on the next release.
